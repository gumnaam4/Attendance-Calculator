📊 Attendance Calculator

A simple and efficient Attendance Calculator that helps students track their attendance percentage and determine how many classes they can miss or need to attend to maintain the required attendance criteria.

This tool is useful for students who want to maintain the minimum attendance requirement (like 75% attendance) in colleges and universities.

🚀 Features

📈 Calculate current attendance percentage

❌ Find how many classes you can skip

✅ Find how many classes you must attend to reach required attendance

🧮 Simple and fast calculations

💻 Easy-to-use interface

📱 Works on desktop and mobile browsers

🧠 How It Works

The calculator uses the basic attendance formula:

Attendance % = (Classes Attended / Total Classes) × 100

Based on the required attendance percentage (usually 75%), it calculates:

How many classes you can bunk

How many classes you must attend continuously
